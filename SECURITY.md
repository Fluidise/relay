# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `fluidise-relay`, please report it responsibly:

- **Do NOT create a public issue** on GitHub.
- Submit a report via GitHub Private Vulnerability Reporting on the repository if enabled, or email the maintainers directly at `security@fluidise.com` or `mayeul.desbazeille@gmail.com`.
- Include detailed steps to reproduce the vulnerability, along with proof of concept if applicable.

We will review your submission promptly and coordinate a fix and advisory release.
